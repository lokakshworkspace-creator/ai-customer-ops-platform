# Cancelling an order

## Orders that can be cancelled

An order can be cancelled while its status is {{cancel.cancellable_statuses}}, that is, before it has been paid. Ask the assistant to cancel it and it happens immediately.

## Paid orders

An order that is {{cancel.refund_required_statuses}} cannot be cancelled. Instead, request a refund for it; the refund rules apply, including the time limit of {{refund.max_order_age_days}} days.

## Shipped and delivered orders

Once an order has shipped it cannot be cancelled. When it arrives you can return it under the returns policy.

## Already cancelled orders

An order that is already cancelled cannot be cancelled again.
